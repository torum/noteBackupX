# noteBackupX

A simple GUI backup tool for note.com.

Because note.com lacked a backup or export feature for user-generated content, I initially spent a few hours building a simple backup tool for myself. Four years later, the official export feature exists but remains non-functional, so I spent half a day rebuilding the app using Avalonia UI to make it fully cross-platform.

Please note that this app is provided as-is. Due to the nature of this tool and low demand and low usage, the app has a limited feature set and will receive minimal updates.
